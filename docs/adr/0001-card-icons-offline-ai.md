# Card Icons are offline AI PNGs with transparent square canvases

Card pick UI needs a chibi Card Icon per Card. We commission icons offline from an Icon Brief (name, description, kind, style tags), ship them as square PNGs (~256×256) with transparent backgrounds, and load them at runtime—rather than generating at pick time or sharing one icon across a base item and its upgrades. Transparent alpha is for cutout only; UI display size is roughly 96–128 px so icons stay sharp on the existing ~180×220 card buttons. Runtime resolution is by convention: `res://assets/cards/{Card.Id}.png` (no per-card path field); missing files fall back to text-only. Art matches existing hero chibi language (symbolic item/effect, not a full hero). First delivery includes CardPopup wiring and a full offline icon set for every Card id. Transparency is enforced by generation constraints and spot-check/regenerate—not by an automated background-removal script.
